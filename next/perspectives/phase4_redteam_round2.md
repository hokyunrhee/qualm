# Phase 4 red team, round 2

The full findings, with the 15 new attacks and per-candidate results, are in `next/eval/attacks/round2/FINDINGS.md`; the attacks are built by `next/eval/attacks/round2/build.py`.

Headline: two one-line edits made the shared perimeter skip a file silently, a regression against qualm 0.1.1:
- `minified_by_long_line`: one long line made a Go file read as minified;
- `generated_known_generator`: a "Code generated by stringer" header was trusted because the base already used stringer.

Copies of code in another directory (`cross_dir_copy`, `py_cross_module_copy`) were invisible to the copy index, which only read the changed file's own directory. A new file under an existing `vendor/` is skipped (`vendor_preexisting`), and a judged file over 1 MB was analysed from its first megabyte (`huge_file_truncation`).
